# Sanity Studio — Мой септик

1. Создайте проект на [sanity.io/manage](https://www.sanity.io/manage).
2. Скопируйте `.env.example` → `.env` и укажите `SANITY_STUDIO_PROJECT_ID`.
3. `npm install && npm run dev` — локальная админка.
4. `npm run deploy` — публикация на `*.sanity.studio` (бесплатно).

Схемы: `schemaTypes/`. Структура меню настроена в `sanity.config.ts`.
