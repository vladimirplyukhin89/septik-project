## Структура страницы

Порядок блоков сверху вниз:

1. **Hero** — оффер, CTA, телефон, доверие, счётчики (срок монтажа, гарантия, объём, цена).
2. **Партнёры** — Евролос (официальные представители), Евробион, Топол-Эко / Топас.
3. **Решения для участка** — три схемы: высокий УГВ, колодец рядом, сложный монтаж.
4. **Каталог** — компактная станция, вертикальный и горизонтальный септик; цена от 45 800 ₽; полоса «Форматы корпусов».
5. **Преимущества** — шесть опор: гарантия, сервис, стабильность, грунт, сезон, мощности завода.
6. **Комплект под ключ** — состав работ и стоимость с count-up.
7. **Наши работы** — мозаика фото объектов, лайтбокс.
8. **FAQ** — монтаж, УГВ, колодец, гарантия, чужая ёмкость.
9. **О компании / контакты** — юрлицо, адрес, телефон.
10. **Форма заявки** — имя, телефон, комментарий.

Отдельные поверхности: липкий хедер, мобильное меню, модалка «Обратный звонок», нижняя CTA-полоса в каталоге на мобиле.

## Навигация

Одна страница, якоря:

| Пункт | Якорь |
|--------|--------|
| Партнёры | `#partners` |
| Продукция | `#products` |
| Преимущества | `#why` |
| Под ключ | `#package` |
| Работы | `#works` |
| FAQ | `#faq` |

Десктоп (от 1280px) — инлайн-меню в шапке. Ниже — бургер: полноэкранный оверлей на Motion (круговой `clip-path`, stagger пунктов). Страница не прыгает при открытии (компенсация ширины скроллбара).

## Контент и оффер

- Три линейки пластиковых решений, без перегруза SKU.
- Партнёры-заводы как доказательство, не как витрина чужих сайтов.
- Комплект: ёмкость, трубы, подключение к дому, теплоизоляция, греющий кабель, земляные работы, доставка по Тюмени.
- Заявки: форма на странице, модалка, телефон. Бэкенд `POST /api/lead` → amoCRM + Telegram (или лог, если нет ключей).

Контент: локальный fallback в `web/src/content/fallback.ts`; при настроенном Sanity — тексты, цены и фото из CMS.

## Стек

| Слой | Решение |
|--------|---------|
| Фронт | Astro 7, Tailwind 4, шрифт Manrope |
| Анимации | Motion 13, чанки грузятся по секциям |
| Контент | Sanity (опционально) + локальный fallback |
| Админка | `studio/` — Sanity Studio |
| Заявки | `web/src/pages/api/lead.ts` |
| Хостинг | Vercel adapter, `output: 'server'`; главная `prerender: true` |
| Аналитика | Яндекс.Метрика + цель `lead_submit` |

Монорепо: `web/` (сайт) и `studio/` (админка).

## Дизайн и UX

Тёмная «бумажная» палитра, акцент — бирюза. Карточки без подпрыгивания: ховер через бордер и внутреннее свечение. Продуктовые фото — `object-fit: contain` на студийном фоне. Motion уважает `prefers-reduced-motion`.

На мобиле: бургер, крупные пункты меню, липкая CTA в каталоге.

## SEO

- Title / description (локально и из Sanity).
- Canonical, Open Graph, Twitter card.
- JSON-LD `LocalBusiness` (название, телефон, адрес, Тюмень).
- Sitemap (`@astrojs/sitemap`).
- Язык: `ru`.

---

## Что сознательно не входит

- Отдельные страницы услуг, блог, личный кабинет.
- Корзина и онлайн-оплата.
- Полноценный каталог моделей с фильтрами.
- Редактирование Sanity-строк на проде без админки: если в CMS осталась старая цена, fallback её не перебьёт.

---

## Как развивать

- Следить, чтобы цены в Sanity совпадали с hero / комплектом / каталогом.
- Новые фото работ — в галерею объектов, не в каталог корпусов.
- Новые якоря — сразу в хедер (десктоп + мобильное меню).
- Производительность: видео в hero, JPG работ и Google Fonts — главные веса; подробности в [PERFORMANCE.md](./PERFORMANCE.md).
