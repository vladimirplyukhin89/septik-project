# Moodboard: «Мой септик»

Визуальное направление: **современный производитель** (как [Евролос](https://eurolos.ru/)) + локальный цех/металл. Чистый корпоративный UI, продуктовые карточки, цифры доверия — без Tilda-шума и без копирования синего бренда Евролос один в один.

## Главный референс

**[eurolos.ru](https://eurolos.ru/) — эталон структуры и «современности»**

Берём:
- Светлый чистый фон, много воздуха, sans-типографика
- Hero → блок цифр (производство / склады / дилеры) → каталог продуктов
- Карточки серий: бейдж/технология, название, короткое описание, цена «от», 2–3 характеристики, CTA
- Нумерованные преимущества (01, 02…) с иллюстрацией смысла
- Телефон и «Обратный звонок» всегда в шапке
- Спокойный industrial/corporate look производителя

Не берём:
- Синий бренд и логотип Евролос
- Глубокое мега-меню и каталог на 15+ SKU (у нас 3 продукта)
- Акцент на биостанции/пластик — у нас металл, ЖБ, цех

## Принципы визуала (Eurolos-like для «Мой септик»)

| Токен | Решение |
|-------|---------|
| Фон | Белый / светло-серый `#F4F6F8`, без «бумажной» текстуры |
| Акцент | Стальной синий `#0B6E99` (свой, не Евролос) + тёмный ink |
| Цена / акцент 2 | Тёплый янтарь `#C45C26` только для цены и CTA-secondary |
| Шрифты | Весь UI sans (`Manrope`); display без тяжёлого serif |
| Hero | Светлый/тёмный split или фото цеха + крупный H1 + CTA + stats strip снизу |
| Карточки | Каталожные: медиа-зона, бейдж, цена от, specs, кнопка |
| Motion | fade-up секций, hover на карточках/CTA |

## Что берём с текущего сайта заказчика

- Фото производственного цеха и гидроизоляции
- Оффер: под ключ за 1 день, гарантия 5 лет, от ~45 800 ₽
- УТП: высокий УГВ, колодец рядом, собственный цех
- Контакты: г. Тюмень, ул. Елецкая, 1, тел. +7 (3452) 53-59-73, ООО «АРМАДА»

## Чего избегаем

- Фиолетовые градиенты, glow, «AI SaaS»
- Копия палитры/лого Евролос
- Десять одинаковых CTA, квиз на 12 шагов
- Стоковые улыбки вместо цеха
