# Moodboard: «Мой септик»

Визуальное направление: **тёмная канва промышленного бренда** (компоновка как [Systeme Electric](https://systeme.ru/)) + локальный цех/металл. Карточки, цифры доверия, без Tilda-шума и без копирования teal Systeme.

## Главный референс компоновки

**[systeme.ru](https://systeme.ru/) — тёмная канва, сетка блоков, воздух**

Берём:
- Почти-чёрный фон страницы, шапка того же тона, белый текст
- Split-заголовки: крупный H2 слева, лид справа
- Карточки на чуть более светлой поверхности + тонкая светлая обводка
- Фото-плитки с оверлеем и подписью снизу
- Телефон и «Обратный звонок» всегда в шапке
- Один яркий акцент на CTA и ссылках

Не берём:
- Techno Green `#00AC86` и символ ê — это бренд Systeme
- Мега-меню, каталог на десятки SKU, слайдер промо-кампаний
- Изумрудные обводки карточек «один в один»

## Принципы визуала (Systeme-like канва для «Мой септик»)

| Токен | Решение |
|-------|---------|
| Фон | Почти-чёрный `#080C14`, карточки `#121A28`, без светлых секций |
| Акцент | Стальной синий `#0B6E99` (свой, не Systeme teal) |
| Цена / акцент 2 | Тёплый `#E06A2E` только для цены |
| Шрифты | Весь UI sans (`Manrope`); display без тяжёлого serif |
| Hero | Тёмный full-bleed + крупный H1 + CTA + stats strip снизу |
| Карточки | Медиа, бейдж, цена от, specs, CTA; обводка `white/10` |
| Motion | fade-up секций, hover на карточках/CTA |

## Что берём с текущего сайта заказчика

- Фото производственного цеха и гидроизоляции
- Оффер: под ключ за 1 день, гарантия 5 лет, от ~45 800 ₽
- УТП: высокий УГВ, колодец рядом, собственный цех
- Контакты: г. Тюмень, ул. Елецкая, 1, тел. +7 (3452) 53-59-73, ООО «АРМАДА»

## Чего избегаем

- Фиолетовые градиенты, glow, «AI SaaS»
- Копия палитры/лого Евролос
- Десять одинаковых CTA, квиз на 12 шагов
- Стоковые улыбки вместо цеха
